# Android-оболонка (APK)
Відкриває вашу гру з вашого сервера. 1) У MainActivity.java змініть GAME_URL на адресу, яку показує server.js (наприклад http://192.168.1.5:3000 або https-адресу тунелю).
2) Завантажте цю папку на GitHub (разом з .github) → Actions → Build APK → завантажте app-debug.apk з Artifacts. Або відкрийте папку в Android Studio → Build APK.
