СМУРФО-СТРЕЛЯЛКА 2.0 — гра для завантаження
===========================================

ЩО ТАМ
  index.html  — сама гра
  server.js   — ігровий сервер (потрібен тільки Node.js, https://nodejs.org , версія 16+; npm install НЕ потрібен)
  start.bat / start.sh — запуск сервера двома кліками
  android-apk-project — проєкт для збірки APK (необов'язково)

ЯК ГРАТИ З ДРУГОМ
1) На комп'ютері, який буде сервером, запустіть start.bat (Windows) або start.sh (Mac/Linux).
   У вікні з'являться адреси, наприклад:  http://192.168.1.5:3000
2) Та сама Wi-Fi мережа: ви й друг відкриваєте цю адресу в браузері (Chrome) на телефоні чи комп'ютері.
   У Chrome на Android: меню ⋮ → «Додати на головний екран» — гра відкриватиметься як застосунок на весь екран.
3) ОНЛАЙН → СТВОРИТИ СЕРВЕР (один гравець), другий бачить його в списку й натискає УВІЙТИ.

ГРА ЧЕРЕЗ ІНТЕРНЕТ (друг в іншому місці)
  Варіант А — тунель (найпростіше): встановіть ngrok або cloudflared і виконайте
      ngrok http 3000
      Друг відкриває https-адресу, яку покаже ngrok.
  Варіант Б — хостинг: завантажте папку на будь-який хостинг Node.js (Render, Railway, Fly.io…),
      команда запуску:  node server.js   (порт береться зі змінної PORT).
  Варіант В — відкрити порт 3000 на роутері (port forwarding) і дати другу адресу http://ВАШ_ІР:3000

ОФЛАЙН-БІБЛІОТЕКА (необов'язково)
  Гра сама підтягує 3D-бібліотеку з інтернету. Щоб працювати без неї, завантажте файл
  https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
  і покладіть його поруч з index.html під назвою three.min.js.

ЯКЩО ВІДКРИВАЄТЕ index.html НАПРЯМУ ЯК ФАЙЛ
  У меню з'явиться поле «Адреса сервера» — впишіть, наприклад, 192.168.1.5:3000 .

ТРЕНУВАННЯ працює без сервера.
